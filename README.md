## 👋 About Me

I'm a full-stack web developer from Indonesia who builds **real products for real businesses** — affiliate marketing tooling, e-commerce dashboards, and management apps that run in production every day.

- 🚀 Currently building **[Racun Studio](https://racun-studio.vercel.app)** — a toolkit of 15 Facebook distribution tools for affiliate marketers
- 🛒 I run multi-platform affiliate operations across **Shopee, Tokopedia, Lazada & Blibli**
- 🧩 I like turning messy marketing workflows into clean, automated web apps
- 📍 Based in Indonesia · on GitHub since 2020
